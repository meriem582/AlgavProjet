Le projet consiste à représenter un dictionnaire de mots. Dans cette optique, on a utiliser deux structures de tries concurrentes Patricia-Trie et Hybride-Trie.
Prérequis Pour exécuter ce projet, vous aurez besoin de Java installé sur votre machine. La version utilisée pour le développement est la version 17. 
*Langage : Java *Version : 17.0.10 (LTS) 
*Date de sortie de la version : 2024-01-16
Environnement d'Exécution et Compilateur 
*Environnement d'exécution : Java(TM) SE Runtime Environment (build 17.0.10+11-LTS-240) 
*Compilateur : javac version 17.0.10
